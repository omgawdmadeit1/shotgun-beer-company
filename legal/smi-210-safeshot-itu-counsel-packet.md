### Class 21 — bottle openers

```
Bottle openers, electric and non-electric
```

| ID Manual string | Why it is here |
|---|---|
| Bottle openers, electric and non-electric | Nice Class 21 home (NCL 210048). Covers the bottle-opener end of the tool |

**Classification note vs. the issue title.** SMI-210 says “Class 21 (can/bottle openers).” Under current Nice, **non-electric can openers are Class 8**, bottle openers are Class 21. ## 6. 2(e)(1) descriptiveness — expected pushback

“Safe” + “shot” on a tool that makes shotgunning safer is the **harder** mark. File anyway. Plan the response now.

**Do not hand the examiner the refusal**

- No Trademark Center “significance” statement that defines the mark
- No specimen or website line that says “SAFESHOT — the safe shot” / “safer shotgun tool” / “the safe way to shotgun”
- Always present as a product under the house brand: **SIDESHOT™ SafeShot™ tool**
- Use ™ now. ® only after registration

**Response outline if a 2(e)(1) issues**

1. Suggestive, not merely descriptive. Consumers must pause to connect SAFE + SHOT to a punch / opener. The mark does not immediately describe “hand tools, namely, punches” or “bottle openers.”
2. Compound / coined presentation as one word (SAFESHOT), not “SAFE SHOT.”
3. Third-party “shot” marks in unrelated goods do not make this descriptive of tools.
4. If Principal Register fails: accept **Supplemental Register**, keep selling, then move §2(f) after five years / acquired distinctiveness.
5. **Stylized fallback** (separate application) once Harper locks the can-silhouette art (SMI-151 / SMI-175). File that as a second mark, not a substitute for this standard-character ITU.
