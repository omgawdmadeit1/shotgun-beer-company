## 3. Goods — ID Manual picker only (avoid +$200/class)

USPTO Trademark Center (post-2025-01-18): base **$350/class** if every identification is chosen from the ID Manual inside the form. Typing the same words into the free-form box still triggers the **+$200/class free-form surcharge**. Keep each class under 1,000 characters.

Search each line in [ID Manual](https://idm-tmng.uspto.gov/) and **click the matching active entry**. Do not compose a custom string.

### Class 32 — Light beverages (beer)

Select these **seven** active entries (or the closest current active synonym if an entry was retired):

1. Beer
2. Ale
3. Lager
4. Stout
5. Porter
6. Craft beer
7. Malt liquor

**Do not add:** hard seltzer, flavored malt beverages except beer, wine, spirits, non-alcoholic beer (unless we actually intend to sell it), “shotgun beer,” or any custom ritual language.

Expected concatenated ID (for character-count check only — still pick via the Manual):

`Beer; Ale; Lager; Stout; Porter; Craft beer; Malt liquor.`

Character count ≈ 58. Well under 1,000.

These wordings appear as accepted Class 32 identifications on live USPTO records (e.g. combined “Beer, ale, lager, stout and porter” / standalone “Craft beer” / “Malt liquor”). Counsel must still confirm each line is **Status: A (Active)** in the ID Manual on filing day.

### Class 25 — Clothing

Select these **four** active entries:

1. T-shirts
2. Hats
3. Hooded sweatshirts
4. Baseball caps

**Do not add:** koozies (Class 21), bottle openers, “shotgun merch,” or free-form “clothing, namely…”.

Expected concatenated ID:

`T-shirts; Hats; Hooded sweatshirts; Baseball caps.`

Character count ≈ 52.

Locked Phase 1 merch SKUs (SS-TEE-01, SS-HAT-01) fit these IDs. SS-KOO-01 (koozie) is **not** Class 25 — leave it off this application.
