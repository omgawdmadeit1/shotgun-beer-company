# SMI-144 — Trademark search & filing strategy: SIDESHOT / SafeShot

**Search date:** 2026-08-27  
**Scope:** USPTO word-mark clearance for SIDESHOT (Class 32 beer + merch/tool classes), SAFESHOT (tool classes), SIDE QUEST secondary language, plus prior-art patents on side-opening / shotgun cans.  
**Verdict:** File SIDESHOT now. File SAFESHOT as a tool mark only. Do **not** file SIDE QUEST in alcohol classes. Phase 1 standard cans + companion tool stays clear of the live dual-mouth *can* patents; SafeShot hardware still needs a design-around FTO.

This is an operator clearance memo, not a substitute for counsel. A trademark attorney should file through USPTO Trademark Center and run a paid full search (federal + state + common law + domain) before money is spent.

## 2. USPTO search — SIDESHOT

### 2.1 Class 32 (beer) — no live block

No live or pending **SIDESHOT / SIDE SHOT / SIDE-SHOT** word mark was found in Class 32 (beer, ale, lager, malt beverages) or Class 33 (other alcohol). Dead **SHOTGUN**-formative beverage marks exist and do not block:

| Mark | Serial / Reg | Class | Status | Why it matters |
|---|---|---|---|---|
| SHOTGUN | 78353294 | 32 beer | Dead — abandoned, no SOU | Shows “SHOTGUN” for beer was attempted and died. Not a bar. |
| SHOTGUN | 85840664 | 32 energy/sports drinks | Dead | Vital Pharmaceuticals. Dead. |
| SHOTGUN BETTY | 85489614 / 4185751 | 32 | Dead | LoneRider Brewing. Cancelled/dead. |
| Shotgun Hard Seltzer | — | marketplace | Discontinued (2024) | Common-law residual possible but brand is off-shelf. SIDESHOT is not SHOTGUN. |

**Examiner likely-confusion (2(d)) takeaway:** SIDESHOT is not SHOTGUN, not SURE SHOT, not SIDE QUEST. No identical Class 32 senior user found. File.

### 2.2 Cross-class SIDESHOT users (coexistence, not blocks)

These are live or commercial uses of SIDESHOT / SideShot in **unrelated** goods. They do not occupy Class 32. They are why we should **not** file SIDESHOT in HVAC, cameras, or industrial imaging.

| User | Goods | Class (approx.) | Conflict with beer/tool? |
|---|---|---|---|
| Tjernlund Products, Inc. — **SideShot®** RV 2558688 (commonly cited) | Sidewall mechanical vent systems (SS1/SS2) | 11 environmental control | No. Different goods, channels, consumers. |
| We R Memory Keepers / We R Makers — ShotBox **SideShot** arm | Camera arm for a portable photo studio | 9 (product name; house mark is WE R MEMORY KEEPERS RN 4190443) | No for beer. Do not brand a camera accessory SIDESHOT. |
| Park Industries — **SIDE-SHOT™** photo station | Granite-slab imaging station | Industrial equipment | No. |

Sony’s Taiwan **Side Shot** (projectors, Class 9) expired 2023-05-15. Not a US bar.

### 2.3 Suggested SIDESHOT identification (ID Manual — stay under 1,000 characters)

- **Class 32:** Beer; ale; lager; stout; porter; malt liquor; craft beer.
- **Class 25:** T-shirts; hats; hooded sweatshirts; baseball caps.
- **Optional later Class 35:** On-line retail store services featuring clothing and beverage-can opening tools.
- **Optional later Class 21 (house mark on the tool):** Bottle openers; can openers.

File 32 + 25 now. Add 35 after DTC is live and specimens exist. Putting the tool under SIDESHOT (house mark) is optional; the product name should be SAFESHOT.

### 2.4 Descriptiveness (2(e)(1)) — SIDESHOT

Risk is **manageable if we stay suggestive**.

- **Safe argument:** SIDESHOT is a coined compound. Consumers must pause to connect “side” + “shot” to beer or a ritual. That is suggestive, not merely descriptive.
- **Unsafe copy:** “SIDESHOT — the beer with the side shot” / “side-shot opening” as the brand explanation. That hands the examiner a descriptiveness refusal.
- **Site/COLA rule:** Use SIDESHOT as the brand. Describe the ritual as “Start the Side Quest” or “own the moment.” Do not define the brand as the feature.

If a 2(e)(1) issues: argue suggestive + submit any acquired-distinctiveness evidence; fallback Supplemental Register, then §2(f) later.

3. If refused on the Principal Register, accept Supplemental Register for the word mark and keep selling. Supplemental still blocks later identical filings and supports a later §2(f) move.

TTAB has treated beer and wine/spirits as related goods (e.g. *In re Dead Bird Brewing*, *No Boundary IPA*). A Class 32 SIDE QUEST filing would likely draw a 2(d) refusal against SN 99944596 and possibly an opposition. A taproom named Side Quest would collide with RN 5017598.

**Policy:** Side Quest stays a **slogan / merch motif**, not a SKU name and not a federal alcohol mark. Optional later: Class 25 slogan registration of a full phrase (“START THE SIDE QUEST”) if it functions as a mark, with a disclaimer of SIDE QUEST if required.

## 5. Patent landscape — side-opening / shotgun cans and tools

Trademarks do **not** give the right to make a dual-mouth can. Patents do not block the SIDESHOT brand. Split the two.

### 5.1 Can patents — Phase 1 is clear; custom dual-mouth is not “free”

| Patent | Status | What it covers | SIDESHOT impact |
|---|---|---|---|
| **US20150183547A1** — Langheinrich, “Shotgun accessible beer can” | **Abandoned 2017-01-10** (failure to respond) | Scored / perforated side opening near the base of a pressurized can | **Prior art, no exclusive rights.** The generic idea of a second scored side hole is in the public domain. Anyone can practice a simple scored side opening. We cannot exclude competitors with this abandoned application. |
| **US6015060A** — dual-aperture beverage container + side vent opener | **Expired** (20-year term from late-1990s filing) | Side-wall scored vent + rim-hook opener; bottom vent variant | Public domain. Useful prior art if we later file our own utility. |
| **US11,814,210 B2** — Benson, “Dual mouth shotgun can” | **Live.** Filed 2023-05-15 as 18/197,170 | **Narrow:** twistable upper/lower body, pushrod from top mouth to lower scored mouth, aligned outer opening | **Do not ship this architecture.** Phase 1 standard cans + SafeShot tool does not practice these claims. |
| **US12,534,267 B2** — Benson CIP, granted **2026-01-27** | **Live.** Appl. 18/377,233 | **Narrow (1 claim):** main body + connecting rod + butterfly tab; twistable upper/lower body; rod from butterfly tab to lower mouth | Same. Design-around is easy if we never add an internal rod + twist body. |
| US20260028148A1 family / dual-aperture drinking containers | Watch | Dual apertures for flow + air | Monitor; do not copy scored-side + internal linkage. |

**Phase 1 product (branded standard cans + SafeShot tool) does not infringe the live Benson can patents.** Those claims require a two-part twist body and an internal connecting rod / pushrod tied to the top tab.

**Phase 2 custom side-opening can:** a *simple* additional score on a one-piece can wall (Langheinrich-style) is likely free. A tab-linked, twist-to-align, or rod-actuated second mouth is **occupied**. Any custom can needs a written FTO before tooling with Ball/Crown.

### 5.2 Tool patents — this is the real SafeShot risk

SafeShot is a punch + bottle opener + tab lifter (SMI-147). Live patents in this exact category:

| Patent | Owner | Expires (approx.) | Claim flavor | Design-around |
|---|---|---|---|---|
| **US10,961,101 B2** | Chug Co, LLC (Flint, TX) | ~2039-01-09 | Body shell + **slidable piercing tube** + drinking spout + **trigger latch** holding an armed position; optional spring | Do **not** build a spring-loaded sliding tube with a trigger and integral drink passage. |
| **US11,731,868 B2** / **US11,993,500 B2** | Wild Man Lab LLC | ~2042 | Pivot arm that seats on the can bottom, curved piercing/entry portion, shroud, flow apertures into a spout | Do **not** copy the bottom-hook + curved pierce-and-drink geometry. Wild Man has already litigated (D. Del. 1:24-cv-00071). |
| **US11,903,502 B2** | Miles Wing | — | Can insulator + shotgun straw / dual conduit | Different (koozie + straw). Don’t combine insulator + pierce conduit in the same way. |

**SafeShot path that stays clean:** a **simple rigid punch / key-style piercer + bottle opener + tab lifter**. No sliding tube, no trigger, no drink-through spout, no bottom pivot hook, no insulator+straw. That is also the cheapest first 50–200 unit geometry (SMI-147 / SMI-153).

Counsel should map the CAD (SMI-153) claim-by-claim against 101 / 868 / 500 **before** the RFQ goes out.

## 6. Filing package (how to file, what it costs)

USPTO retired TEAS Plus/Standard on **2025-01-18**. New applications go through **Trademark Center**.

| Item | Government fee (2026) | Notes |
|---|---|---|
| Base application | **$350 per class** | Complete application + ID Manual wording + ID < 1,000 characters. |
| Insufficient-information surcharge | +$100 / class | Avoid by completing every Trademark Center field. |
| Free-form ID (not in ID Manual) | +$200 / class | Do not write custom “shotgun multi-tool” IDs. |
| Extra 1,000 ID characters | +$200 / class | Keep IDs short. |
| Statement of use (later) | check current fee | Due after ITU notice of allowance (6-month windows, extensions available). |

**Recommended first packet**

| Application | Classes | USPTO fees | Counsel (ballpark) |
|---|---|---|---|
| SIDESHOT — standard character, §1(b) | 32 + 25 | $700 | $1,200–2,500 all-in |
| SAFESHOT — standard character, §1(b) | 8 + 21 | $700 | $1,000–2,000 all-in |
| **Total to lock priority** | 4 classes | **$1,400** | **~$2,500–4,500** |

Skip Class 35 until the store is live. Skip a logo application until the can-silhouette mark is final (Harper / SMI-151). Skip SIDE QUEST alcohol filings entirely.

**Owner of record:** file in the operating entity that will sell (not a personal name if a company exists). If no entity yet, file in the founder’s name and assign into the LLC the week it is formed. Wrong owner is expensive to fix.

**Basis:** §1(b) intent-to-use. We do not have interstate beer commerce yet. ITU locks the filing date. After allowance, we have 6 months (extendable to 36) to file a statement of use with specimens:

- Class 32: labeled can, tap handle, or bona fide product shot in commerce (not a mockup).
- Class 25: hangtag / Printify SKU actually sold or transported in commerce (SMI-150).
- Class 8/21: SafeShot unit sold or bona fide pre-sale in commerce (SMI-148), not just a render.

**Use ™ now.** Switch to ® only after registration.

## 7. Parallel tracks (not USPTO, still brand-critical)

1. **TTB COLA** — required before interstate malt-beverage labels. Brand name on the COLA should be **SIDESHOT**, not Side Quest, not SafeShot.
2. **State trademarks** — optional cheap backup in the formation state if counsel wants a belt-and-suspenders common-law marker. Federal ITU is the priority.
3. **Domains / social** — SIDESHOT is the house. Hold safeshot.* if cheap; do not build a second consumer brand there.
4. **Product liability copy** — 21+, responsible-use, no drain-time claims (SMI-146). This is not a trademark issue but it is how examiners and platforms will read the specimens.
5. **Watch docket** — set a 30-day watch on SN 99944596 (SIDE QUEST seltzer), SN 98831421 (SURE SHOT), and RN 8061021 (SAFESHOT targets) for expansions into Class 8/21/32.
